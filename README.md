### What I learned
After I built this, I learned centering the container of the homepage and I found out of my best approach of this using `margin:auto`. 

#### Here is my approach 
.container {
    display: flex;
    flex-direction: column;
    align-items: center;
    min-height: 100vh;   
}

.wrapper {
    margin: auto; 
}
